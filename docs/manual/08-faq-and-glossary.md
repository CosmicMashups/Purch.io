# 8. Questions, troubleshooting and glossary

## Questions

**I do not see a tab or tile.** Your role does not include it. Ask an Admin to check your role under Business, Staff.

**The register says "Sign in with a device to sell".** Cashiers must use a paired register. Ask an Admin to pair this device.

**A discount, price change, void or refund asks for a PIN.** This is by design. A Manager or Admin types their own PIN, every time.

**I forgot my PIN or password.** Ask an Admin for a new invite link. It lets you choose a new password and PIN.

**My PIN is locked.** Too many wrong tries lock that person for a while. Wait, or ask a colleague to help while you are locked out.

**A customer's receipt number is missing.** Receipt numbers are sequential and never skip. If the Z-reading shows missing numbers, a sale may have been interrupted; check Orders and the Audit log.

**The sale did not go through on a bad connection.** Do not tap Charge again. Check Orders or use Find order. Payments are protected against double charging.

**Can I sell without internet?** Not in the web app. See [When the internet drops](07-devices-and-hardware.md#when-the-internet-drops).

**Can I give a customer points or a loyalty card?** Not yet. Customer profiles, loyalty, gift cards, tips and table management are not available.

**The tax report and the Z-reading differ by a few centavos.** The report adds up each sale as it was rounded. Use the Z-reading as the BIR record.

**Stock went negative after a count.** Counts apply the difference from the moment of counting, so sales after counting can push a line below zero. Check the audit entry for the list.

## Good daily routine

1. Open shift with the opening cash count.
2. Sell; park carts when a customer steps away.
3. Take an X-reading at the middle of the day if needed.
4. Close shift with a blind cash count; a manager PIN if there is a difference.
5. Manager takes the Z-reading.
6. Warehouse records deliveries and spoilage as they happen; count stock on a schedule.

## Glossary

| Term | Meaning |
|---|---|
| **BIR** | Bureau of Internal Revenue, the Philippine tax authority. |
| **TIN** | Tax Identification Number printed on receipts. |
| **VAT** | Value-added tax, 12%. |
| **VATable / VAT-exempt / zero-rated** | Sales with tax / without tax by law (such as Senior/PWD) / taxed at 0%. |
| **Senior / PWD** | Senior citizen or person with disability: 20% discount and VAT exemption by law. |
| **X-reading** | Mid-day sales summary. Does not close anything. |
| **Z-reading** | End-of-day close for BIR. Resets the daily counter. |
| **Utang** | Customer credit: take now, pay later. |
| **Tingi** | Selling small amounts from a larger pack, such as one sachet. |
| **Park cart** | Set an unfinished sale aside to serve someone else. |
| **Open item** | A one-off item not in the catalog. |
| **Split payment** | Paying one sale with several methods. |
| **Modifier** | An option or add-on to an item, such as sugar level. |
| **Variant** | A version of an item, such as size. |
| **Recipe / BOM** | The ingredients one finished item uses. |
| **Stock-take** | A counting session that compares real stock to the system. |
| **Variance** | The difference between counted and expected quantity. |
| **PO** | Purchase order sent to a supplier. |
| **COGS** | Cost of goods sold. |
| **Kiosk** | A customer self-order screen. |
| **Pairing code** | One-time code that links a device to your business. |
| **Manager PIN** | The PIN of a Manager or Admin who approves a sensitive action. |
