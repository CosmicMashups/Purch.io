# Purch.io User Manual

For business owners, managers, cashiers and warehouse staff using the Purch.io web app. Written for people who are not technical: every step names the button or tab as it appears on screen.

Screenshots use a demo shop, "Kapihan ni Aling Nena". The people, products and prices are made up.

## Chapters

2. [Selling at the register](02-selling.md): cart, discounts, open items, parking, payment, receipts, refunds, exchanges, shifts, cash counts and X/Z readings.
3. [Items, categories and promotions](03-catalog-and-promotions.md)
4. [Inventory and purchasing](04-inventory.md): stock movements, ingredients and recipes, purchase requests and orders, receiving, transfers, stock counts, import and export.
5. [Reports](05-reports.md)
6. [Running the business](06-business-setup.md): staff, branches, devices, settings, customer credit (utang), orders, audit log, sync conflicts.

8. [Questions, troubleshooting and glossary](08-faq-and-glossary.md)

## Who can do what

| Area | Admin | Manager | Cashier | Warehouse |
|---|---|---|---|---|
| Sell, park carts, take payment | yes | yes | yes | no |
| Discounts, price override, refund | with own session | with own session | needs a Manager or Admin PIN | no |
| Senior/PWD discount, void cart | yes | yes | no | no |
| Items and categories | yes | yes | view | view and edit items |
| Stock movements, counts, purchasing | yes | yes | no | yes |
| Apply a stock count, commit an import | yes | yes | no | needs a Manager or Admin PIN |
| Reports | yes | yes | no | stock valuation and COGS only |
| Staff, branches | yes | staff only, branches read-only | no | no |
| Devices, business settings | yes | no | no | no |

The screens you see depend on your role. If a tab or tile is missing, your role does not include it. Ask an Admin.

## Conventions

- **PIN** is the 6 to 8 digit number you use at a shared register. **Manager PIN** means the PIN of any Manager or Admin, entered by that person to approve a sensitive action.
- Peso amounts are shown as ₱.
- A note that says "Admin only" is enforced by the system, not only hidden.
